# Mockup Odaklı Çalışma

Bu proje bir UI mockup'ıdır. Gerçek backend, veri bütünlüğü veya üretim kalitesi hedeflenmez.

- Sadece görünen arayüze odaklan: metin, alan, bölüm, stil değişiklikleri.
- Backend mantığına, veri modeline, tip ya da state temizliğine girme. Bir alan kaldırılacaksa yalnızca UI'dan kaldır.
- Okumayı en aza indir: ilgili satırı grep ile bul, doğrudan düzenle. Geniş keşif yapma.
- git diff, build veya tsc gibi kontrolleri, kullanıcı istemedikçe ya da bir hata yoksa çalıştırma.
- Yanıtları 1-2 cümleyle sınırla.
